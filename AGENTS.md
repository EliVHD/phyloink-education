# PhyloInk education guidance

This repository is a small, finite showcase of independent, educator-adaptable examples. Do not grow it into a course, promise continuing lesson production, or add application labs incidentally. The usage and Teacher's Guides remain authoritative in the application repository; link to them rather than copying them.

Original contributions use 0BSD. Retain each dataset's separate rights, attributions, release identifiers and source bytes. Distinguish empirical sources from invented models. Never resolve polytomies or invent relationships for a neat picture. Explain rooting, selection, branch lengths and sampling limitations. Do not infer biological validity from geometry checks.

Keep each example self-contained: README, editable activity, printable student handout, teacher answers/adaptation notes, project, SVGs, source and verification records. Provide a text description of the principal relationships and make tasks independent of color. Check answers against source relationships, not label proximity.

Use explicit file inventories and checksums when packaging examples. Never include credentials, private reference material, node_modules or local tooling caches. Generated downloads must contain reviewed example files only. Do not change existing releases or publish a release without an owner request. Do not silently change a recorded verification date or label untested files as import-tested.

Before delivery, open projects in the actual application, check active views and source preservation, inspect SVGs and rendered PDF pages, verify local links and ZIP inventories, and report limitations honestly. Regeneration tools may take an explicit application checkout as an authoring input; downloaded examples must not depend on that checkout or a private workspace.
