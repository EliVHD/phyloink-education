# PhyloInk education guidance

This repository is a small, finite showcase of independent, educator-adaptable examples. Do not grow it into a course, promise continuing lesson production, or add application labs incidentally. The usage and Teacher's Guides remain authoritative in the application repository; link to them rather than copying them.

Original contributions use 0BSD. Retain each dataset's separate rights, attributions, release identifiers and source bytes. Distinguish empirical sources from invented models. Never resolve polytomies or invent relationships for a neat picture. Explain rooting, selection, branch lengths and sampling limitations. Do not infer biological validity from geometry checks.

Keep each example self-contained: README, editable activity, printable student handout, teacher answers/adaptation notes, project, SVGs, source and verification records. Provide a text description of the principal relationships and make tasks independent of color. Check answers against source relationships, not label proximity.

Synthetic inheritance/population walkthroughs use explicit manual model parameters, editable handouts, teacher notes, assumptions and verification rather than a tree project/SVG/Newick dataset. Do not imply empirical observations or invent a tree to fit the tree-example structure. Their authoring configuration is not an application scenario format; keep learner state out and the demonstration count bounded. Distinguish finite population trajectories from no-drift references, idealized N from empirical estimates and locus fixation/loss from extinction.

Use explicit file inventories and checksums when packaging examples. Never include credentials, private reference material, node_modules or local tooling caches. Generated downloads must contain reviewed example files only. Do not change existing releases or publish a release without an owner request. Do not silently change a recorded verification date or label untested files as import-tested.

Linkage uses one bounded synthetic phased two-locus test-cross example. Preserve explicit parental/offspring phase, weighted probabilities, uninformative homozygous markers and model-versus-sample distinctions. A recombination fraction is not a crossover count or physical/map distance. No inferred tree genotypes, breeding system or chromosome mapping is added.

Bottleneck/recovery uses one neutral size-schedule example with a constant-size comparison and complete per-generation N/counts. Distinguish target-size reproductive resampling from survivor culling, separate seeded streams from paired individuals and one-locus H from observed genotypes/genome diversity. Recovery cannot recreate absent alleles; individual H can rise. Preserve exact exported CSV bytes and older resources/verification records.

Selection comparisons use one adaptable example with two explicit AA/Aa/aa relative-fitness triplets and shared constant N/initial frequency/horizon. Preserve separate seeded streams, complete counts and unchanged underlying model. Distinguish relative contributions from survival percentages, genotype fitness from phenotype dominance, no-drift balance from finite persistence and theoretical references from finite means. Preserve exact CSV bytes and earlier records. No empirical/tree inference or additional mechanisms.

Worksheet adaptations reuse existing resources and record their exact application build. Keep student and teacher packages separate; do not commit real learner responses, progress or private worksheet content. Preserve source/data rights and configured model/source references, review custom wording and print layout, and keep historical packs/handouts/verification records unchanged. Do not represent export context/authoring records as importable scenarios.

Before delivery, open projects in the actual application, check active views and source preservation, inspect SVGs and rendered PDF pages, verify local links and ZIP inventories, and report limitations honestly. Regeneration tools may take an explicit application checkout as an authoring input; downloaded examples must not depend on that checkout or a private workspace.
