# Common ancestry and clades

**Question:** Among six sampled mammals, which groups share a more recent common ancestor?

This example demonstrates tree interpretation and the value of retaining the larger scientific source. Learners need to recognize a branch and a branching point; no genetics calculations are required. Use it as a short discussion, printed exercise or teacher-led exploration, adapting the questions to your learners.

1. Open `project.treeproject.json` with **Open file** in PhyloInk. The accepted rectangular view should appear.
2. Use [student-handout.pdf](student-handout.pdf), or edit [activity.json](activity.json) or [student-handout.html](student-handout.html).
3. Consult [teacher-notes.md](teacher-notes.md) for checked answers and variations.
4. Compare the small drawing with the full source in Explore. Return to the editor before saving your adapted project.

The six displayed names are Homo sapiens, Pan troglodytes, Gorilla gorilla, Mus musculus, Rattus norvegicus and Oryctolagus cuniculus. Within this selection, human and chimpanzee share an ancestor excluding gorilla; those three form a nested represented group. Mouse and rat form another represented pair. These are statements about the sampled source hypothesis, not a complete inventory of descendants in nature.

The [labeled](artwork/rectangular/tree_labeled.svg) and [unlabeled](artwork/rectangular/tree_unlabeled.svg) SVGs share branch artwork. The unlabeled version can support your own word bank or annotation exercise. Read [SOURCES.md](SOURCES.md) for the Upham et al. dataset, CC0 terms, rooting evidence and limitations. All original source bytes are retained. Labels are shortened for display; this does not change source identities. Branch lengths on the handout are nonmetric. See [verification.json](verification.json) for the tested application build and source-based answer checks.

Adaptation: use fewer taxa for an introduction, substitute another sampled group for a familiar context, or ask learners to explain omitted descendants. Save your new selection separately and recheck every answer against it.
