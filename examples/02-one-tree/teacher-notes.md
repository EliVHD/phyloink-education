# Teacher reference: one tree, different drawings

## Checked answers

On both pages, the source ancestor of Homo sapiens and Pan troglodytes is `n003716`. The represented group including Gorilla gorilla has ancestor `n003715`. Mus musculus and Rattus norvegicus share `n001377`, excluding the other four represented tips. These source identities and all six selected tips are identical across the two views.

No shared ancestry changes between the pages. The views are different layouts of the same projected graph. A branch rotation that keeps all parent/child connections intact also preserves topology. Exchanging daughter branches is different from attaching a lineage to a different ancestor.

The full source contains additional descendants below these nodes. Avoid calling a two-tip representation the complete source clade. See the first example and the included omitted-membership records for sampling context. Neither drawing's branch lengths encode time or genetic distance.

## Discussion and adaptation

Ask students to mark the same three groups on both pages. Require branch tracing when a student proposes that two nearby labels are close relatives. For a shorter activity, show one pair; for an extension, create a fan view using exactly the same tip identities.

You can sketch a rotation on paper. Interactive tree-interpretation activities are a future application proposal, not required by this example. When contrasting a changed topology, label it as a deliberately hypothetical alternative; do not overwrite or misattribute the published source.
