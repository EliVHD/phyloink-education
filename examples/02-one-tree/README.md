# One tree, different drawings

**Question:** Do the relationships among the same six mammals change when the drawing layout changes?

This independent example demonstrates topology versus appearance. Learners should already be able to trace branches and find a common ancestor. It uses exactly the same source and selected tip identities as the common-ancestry example.

Open `project.treeproject.json` in PhyloInk. In **Layout → Saved structured views**, switch between the rectangular and circular views. Both are accepted, saved views. The [two-page student handout](student-handout.pdf) works without devices. Edit [activity.json](activity.json) or [student-handout.html](student-handout.html) to adapt it. [Teacher notes](teacher-notes.md) supply answers and variations.

The same relationships are present in both drawings: human/chimpanzee nested with gorilla, and mouse/rat as another represented pair. Label adjacency around a circle does not establish sister relationships. Branch position and spacing have no calibrated distance or time meaning.

Each `artwork/rectangular/` and `artwork/circular/` directory contains labeled/unlabeled SVGs and the complete supporting export records. The project retains both views and the full original source. Read [SOURCES.md](SOURCES.md) for attribution, CC0 terms, scientific limitations and the display-label shortening. See [verification.json](verification.json) for identical source/selection checks.

Adaptation: use an unfamiliar rotation on paper, introduce a third layout from the same source, or ask learners to diagnose a deliberately different hypothetical topology. Label an invented comparison explicitly and keep it separate from the empirical source project.
