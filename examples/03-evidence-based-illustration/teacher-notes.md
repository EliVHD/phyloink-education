# Teacher reference: evidence-based illustration

## Checked answers

1. In this source selection, Asparagales and Poales share node `n000023`, and Fabales and Rosales share `n000115`. Each is a represented pair, not a claim that the full source node has only two descendants. The source nodes contain eight and four tips respectively. The terminal records represent orders; they are not six species or a supplied classification hierarchy.
2. The original order tree contains 69 terminal records, including gymnosperm outgroups. Six are displayed and 63 are omitted. The drawing therefore does not show all source orders, all plants, or all species. Its branch spacing is a graphical convention; Kew supplies no branch lengths for this input, and the drawing supplies no divergence dates or quantitative amount of change.
3. A suitable caption is: "Selected order relationships from Kew Tree of Life Explorer release 4.0 (Royal Botanic Gardens, Kew and collaborators; Baker et al., 2022). Five flowering-plant orders and Pinales as a represented gymnosperm outgroup are displayed from the 69-tip source. Source bytes are unchanged; taxon selection and nonmetric rectangular layout were prepared in PhyloInk. Data under CC BY 4.0."

Retain the full source/license links in SOURCES.md when distributing a caption and figure. Explain that a common ancestor is a model node, not a named extant order that "turned into" another extant order. Avoid ladder-like progress claims about Amborellales or the gymnosperm outgroup.

## Adaptation

Use the supplied project to demonstrate the difference between the complete source and a selected illustration. Ask learners to identify an omitted source order in Explore, then assess whether adding it helps the stated question. Recheck descendants when the selection changes.

For learners who need fewer unfamiliar labels, supply a separate explanatory glossary with independently sourced organism examples. Keep the actual order identities on the scientific figure. For advanced learners, examine the distinction between a source phylogeny with order-level tips and a classification hierarchy based on supplied ranks.
