# Creating an evidence-based illustration

**Question:** What relationships among five sampled flowering-plant orders and one represented gymnosperm outgroup can this source support?

This example demonstrates a teacher's preparation workflow rather than a complete lesson. It uses six terminal order records from Kew release 4.0: Pinales, Amborellales, Asparagales, Poales, Fabales and Rosales. These labels are orders, not individual species. Pinales is the represented gymnosperm outgroup; the full source contains other outgroups and many omitted flowering-plant orders.

## Reproduce or adapt the illustration

1. In PhyloInk, open **Datasets → Flowering plants · orders + outgroups** (Kew release 4.0).
2. In Layout, search and select exactly the six order records named above. Show selected tips without collapsing their relationships into groups.
3. Choose a rectangular cladogram. This prepared example uses a 180 × 60 mm page, 10 mm margins, 11 pt sans-serif labels and straight connectors.
4. Preview the layout, inspect it, then accept it. Keep the original source rooting and scientific basis. Numerical branch positions in the drawing are nonmetric.
5. Save a project and export the package, retaining references and source paths. The provided `project.treeproject.json` is the checked reference result. Device fonts can change measurements, so inspect your own regenerated layout.
