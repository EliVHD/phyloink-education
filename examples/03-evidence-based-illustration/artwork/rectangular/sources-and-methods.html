Contributing application methods

  • bounded-overview@1.0.0: bounded_overview_v1: begin with the traversal root children; repeatedly split the frontier internal node with greatest original-tip membership (ties by source ID) whose children fit within 100 endpoints. Stop when no further split fits. Save remaining internal frontier nodes as explicit collapses, with distance threshold zero. Preserve every original tip exactly once; no invented edges or omitted taxa.
    An initial display overview, not a biological grouping criterion or evidence assessment. Internal numeric labels are not assigned support meanings. Large root polytomies that exceed the bound are rejected rather than sampled silently.
  • clade-cluster@1.0.0: clade_cluster_v1: allocate measured ordered terminal slots and nested clade intervals; junction transverse coordinate is the interval midpoint; height is one plus maximum child height and nonmetric depth is 1-height/rootHeight. Map to rectangular or unwrapped circular/fan coordinates. Use open compound connectors and radial/horizontal stems. At most eight measured-label slot passes, fixed font size, bounded clade/level offsets and explicit pin conflicts.
    Original application construction inspired by general cluster and subtree-sector concepts; not a reproduction of D3 or the Bachmaier algorithm. Depth, arc length and inner radius are spacing conventions, not time/distance/confidence.
  • compound-validation@3.0.0: compound_scene_validation_v3: retain compound v2 geometry checks and its 500000-operation ceiling. Attachment tests return attached, detached or incomplete. Track incidence completeness independently before stroke/label checks; incidencePassed requires completed attachment checks with no detected failure. Truncation never asserts incidence success or fabricates a detached attachment. Preserve compound v1/v2 implementations for exact saved replay.
    Numerical validation with explicit bounds and work-limit disclosure; no mathematical nonintersection proof, biological peer review or classroom validation.
  • maximal-frontier@1.0.0: maximal_frontier_v1: original-tip-weighted mean descendant distance, strict less-than threshold, protected override paths and explicit collapse/expand/protect rules. Preserve exhaustive original tip memberships.
    Root is explicitly assumed; missing lengths prevent distance-threshold collapsing.
  • newick-parser@1.0.0: Parse one Newick tree, preserving source text, local IDs, raw labels, comments and length tokens. No support type is inferred from numeric labels.
    Only the supported Newick dialect; no sequence inference.
  • selected-taxon-projection@1.0.0: selected_taxon_projection_v1: orient the exact immutable input at its declared root; retain selected-tip paths and root/stem, explicitly collapse requested nodes, suppress only unannotated unlabeled unary intermediate nodes, retain ordered original paths/edge IDs and selected/original/omitted memberships. No selected-tip distance threshold and no inferred support type.
    Selection changes displayed sampling, not the input topology or its evidence. Missing/invalid path lengths remain unknown.
