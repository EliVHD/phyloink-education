# Model, reading and rights

This example uses original synthetic parameters for `linked-two-locus-v1`. There is no empirical genotype/phenotype dataset, supplied source tree or downloaded scientific figure. The original application phase schematic uses labelled homologous chromosome copies with schematic spacing; it makes no physical/map-distance claim. Original activity text, manual configuration, code and diagram use 0BSD. That license does not cover unrelated publisher material or educators' later additions.

Conceptual reading checked **2026-11-17**:

- [NHGRI — Linkage](https://www.genome.gov/genetics-glossary/Linkage), for linked inheritance terminology.
- [MIT 7.014, Spring 2005, Recitation 16 answer key](https://ocw.mit.edu/courses/7-014-introductory-biology-spring-2005/ed9c0e71598f4e9683ffc4a5dd2f0f7c_section16_ak.pdf), for recombination and the 50% bound.

These are optional references only. No upstream text, illustrations, code, videos or data are copied or bundled; no reading URL is fetched automatically. Their own terms apply if you obtain material directly.

The bounded model assumes equal segregation, symmetric recombination, independent parental gamete draws, random fertilization and complete dominance at each of two autosomal loci. Homozygous markers cannot distinguish parental/recombinant routes. No sex-specific recombination, mutation, selection, epistasis, environmental effects, multigeneration breeding, statistical linkage test, rate estimation or chromosome mapping is performed. A finite recombinant proportion can exceed the model fraction's 50% upper bound. A_ means AA or Aa; dominance does not increase transmission.
