# One adaptable selection comparison

Use **Learn → Selection comparisons** in the unreleased A06.3 build recorded in [verification.json](verification.json). See the [application model and workflow](https://github.com/EliVHD/phyloink/blob/49dab3e1e4d89cf91d2de24fd6f91fc93ffedce3/docs/SELECTION-COMPARISONS.md); the authoritative usage and Teacher's Guides remain in the application repository through **Guides**. This is one finite synthetic example to adapt, not a course or a continuing lesson commitment.

Both conditions start with **N = 100**, **100 A copies**, **40 generations**, **four trials per condition** and seed **1**. S1 AA/Aa/aa relative fitness is **1.2/1.1/1**; S2 is **1.2/1.4/1**. Only heterozygote fitness changes, from directional A advantage to heterozygote advantage. The [manual configuration](activity.json) is an authoring record, not an application import format. The abstract locus does not describe organisms in your tree; see [model and reading limits](SOURCES.md).

1. Choose **Use comparison example** or enter the settings manually. Predict both next post-selection, pre-sampling A frequencies before running.
2. Run both conditions and inspect generations 0, 1, 20 and 40. The two plots use identical axes; the shared inspector provides exact A/a counts. Distinguish finite paths from dashed no-drift references.
3. Explain why phenotype dominance does not assign heterozygote fitness. Does heterozygote advantage guarantee persistence in a finite population?
4. Adapt this same example: change one genotype fitness, N or starting frequency while holding other settings fixed, try equal weights for a neutral comparison, or change seed. Matching trial numbers use separate seeded streams, not paired individuals or guaranteed counterfactuals.
5. Use **Create worksheet** for your own prompts/instructions. Keep student and teacher packages separate and review configured reference answers after changing wording. Learner predictions, feedback, progress, cursor overlays and editor artwork are excluded.

[Teacher notes](teacher-notes.md) explain reasoning, exact seeded results and adaptation limits. [Manifest](manifest.json) records exact resources. Downloaded files work locally with no account, server or remote assets. Print at 100% on A4 and review on the intended device. Printed tables select generations 0/20/40; CSV retains all 328 condition/trial/generation records.

The model weights expected random-mating genotype proportions, then samples 2N gene copies. Fitness weights are relative contributions, not survival percentages. No individual genotypes, survival events or pedigrees are tracked. No mutation, migration, linked loci, changing environment, size changes, sex structure, zero-fitness extinction or empirical/tree inference. Missing alleles stay absent; locus fixation/loss is not species extinction. No-drift balance is not guaranteed finite-population persistence; a few paths cannot establish selection, estimate fixation probability or guarantee condition rankings. N and fitness are chosen inputs, not empirical estimates.

`activity.json` and export context are documentation, not project/scenario imports. Practice resets on return to the editor; explicit worksheets retain educator setups and regenerated data. Original text/code/plots use [0BSD](LICENSE). Optional readings retain their own terms and are not bundled. Older resources and their verification records retain their original bytes.
