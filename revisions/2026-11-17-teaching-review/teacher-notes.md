# Educator correction notes

Use these notes with the original examples. Historical handouts and verification records are retained, rather than relabeled as newly tested resources.

## One tree, different drawings

The [original teacher notes](../../examples/02-one-tree/teacher-notes.md) describe interactive tree practice as a future proposal. It is now implemented in **Learn**, including the [six-mammal scenario](../../scenarios/README.md). A paper rotation remains sufficient for the original activity. Rotate complete child subtrees while preserving connections; a rotation does not resolve a polytomy or change ancestry.

## Selection worksheet

The [revised student worksheet](selection/student.pdf) explicitly directs learners to **Learn → Selection comparisons** for the reference curves required by question 2. The printed figures show finite trials only. Enter the printed settings and run both conditions; the dashed no-drift references are question inputs, not finite-trial averages.

The [original answer reasoning and counts](../../labs/selection/teacher-notes.md) are unchanged: first-step frequencies are 23/44 and 13/25; the S2 no-drift equilibrium is 2/3. Finite populations can still lose or fix an allele. Keep teacher-only explanations separate from student distribution.

## Probability estimates from a few trials

Where the original [population](../../labs/population/teacher-notes.md), [bottleneck](../../labs/bottleneck/teacher-notes.md) or [selection](../../labs/selection/teacher-notes.md) notes say a few trials cannot estimate a probability, read this as: **a few trials cannot provide a reliable probability estimate**. A sample proportion can be calculated, but it is highly uncertain with only four trials.

State the event and horizon explicitly. The fraction fixed or lost by generation 40 concerns that bounded event; it is not an estimate of eventual fixation or loss obtained simply by treating the unfinished paths as permanent non-events. These examples do not guarantee persistence under heterozygote advantage, rank every bottleneck path against every control, or establish selection from a rising frequency.

For application-generated population worksheets, the revised default comparison prompt explicitly directs students to run the printed settings in **Learn → Population evolution** and then repeat with all weights equal, keeping N, initial A copies, horizon, trial count and seed fixed. Preserve those instructions when adapting the prompt.
